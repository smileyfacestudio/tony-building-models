# Capture guide / Съёмка и обмеры

## English

Agree on authorized access and a private upload destination before capture. Do not upload site media to this public repository or its issues. Remove or avoid faces, personal papers, access codes, account labels and other sensitive information. Do not open panels, remove covers, climb into unsafe spaces, or touch energized equipment for a photo.

For each property:

1. **Define scope:** identify the building/suite, floors, rooms, excluded spaces and areas you could not enter.
2. **Give spaces stable IDs:** for example `CV255-F1-R001` is an ID pattern, not a confirmed room. Use the same ID in the sketch, filenames, manifest, model and estimate.
3. **Walk through systematically:** one slow video per floor/zone, moving from the entry through connected rooms; name each room aloud. Film room connections and ceiling transitions. Use well-lit still photos for detail; do not rely only on video.
4. **Photograph each room:** overview from opposite corners, all walls, doors/windows, ceiling type and visible pathways, plus context/detail pairs for visible devices. Record only safely visible panel labels and equipment; a label/photo does not prove circuit mapping or available capacity.
5. **Measure scale anchors:** room length and width, ceiling height, door/opening widths and positions, corridor connections and level changes. Record units and measurement method. Measure more than one independent span per modeled zone so the model can be checked. A phone scan without dimensional checks is approximate.
6. **Mark systems:** distinguish visible existing outlets, visible conduit, data points/racks and proposed additions. Record concealed routes as unknown, not straight-line cable lengths. Do not include camera or access-control details in public outputs.
7. **Index evidence:** use `templates/media-manifest.csv` in private storage. Keep originals, capture date, room ID, viewpoint/video timestamp, operator and any limitations. Store relative private paths only in the private copy.
8. **Review completeness:** list missing rooms, inaccessible ceilings, uncertain dimensions and follow-up questions. Sava checks the evidence before quantities become estimate inputs.

Suggested filename pattern: `CV255_F1_R001_YYYYMMDD_001.jpg`. For video evidence, include a timestamp range in the manifest. This is a naming example, not existing evidence.

## Русский

До съёмки согласуйте разрешённый доступ и закрытое место передачи файлов. Не загружай материалы объекта в этот публичный репозиторий или issues. Не снимай либо убирай из передаваемых материалов лица, личные документы, коды доступа, данные аккаунтов и другую чувствительную информацию. Ради фотографии не открывай электрощиты, не снимай защитные крышки, не забирайся в опасные зоны и не касайся оборудования под напряжением.

Для каждого объекта:

1. **Определи границы:** корпус/помещение, этажи, комнаты, исключённые зоны и места, куда попасть не удалось.
2. **Присвой постоянные ID:** например, `CV255-F1-R001` — образец идентификатора, а не подтверждённая комната. Один ID используется на эскизе, в названиях файлов, реестре, модели и смете.
3. **Сними последовательный обход:** одно медленное видео на этаж/зону, от входа через связанные помещения; называй комнаты вслух. Покажи переходы и изменения потолка. Детали дополнительно снимай хорошо освещёнными фотографиями — не полагайся только на видео.
4. **Сними каждое помещение:** общий вид с противоположных углов, все стены, двери/окна, тип потолка, видимые трассы, общий и крупный план устройств. Фиксируй только безопасно видимые маркировки щитов и оборудования; фото таблички не подтверждает распределение цепей или свободную мощность.
5. **Сделай размерные привязки:** длина/ширина комнаты, высота потолка, размеры и положение проёмов, соединения коридоров и перепады уровней. Запиши единицы и способ измерения. Для каждой зоны нужны несколько независимых размеров для проверки масштаба. Сканирование телефоном без проверки размеров — только приблизительная основа.
6. **Отметь системы:** отдельно существующие видимые розетки, трубы/кабельные каналы, сетевые точки/стойки и предлагаемые дополнения. Скрытые трассы отмечай как неизвестные, а не как длину кабеля по прямой. Не публикуй детали камер и контроля доступа.
7. **Веди реестр:** используй закрытую копию `templates/media-manifest.csv`. Сохраняй оригиналы, дату, ID помещения, ракурс/таймкод, автора и ограничения. Относительные пути к закрытым файлам остаются только в закрытой копии.
8. **Проверь полноту:** перечисли пропущенные комнаты, недоступные потолки, сомнительные размеры и вопросы для повторной проверки. Сава проверяет исходные данные до переноса количеств в смету.

Пример имени: `CV255_F1_R001_YYYYMMDD_001.jpg`. Для видео указывай диапазон таймкодов в реестре. Это образец названия, не существующий материал обследования.
