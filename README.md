### Public repository / Публичный репозиторий

Anyone can read and download this package. Write access is separate: send Boris your GitHub username through your existing private channel. Do not post interior photos/videos, detailed electrical or security layouts, client pricing, private storage links, passwords, or personal information here—including issues, pull requests, and attachments. Use an approved private workspace before collecting actual site data. `private/` is ignored by Git as an accident-prevention measure, **not** an access-control or encryption system. Making the repository private later cannot recall copies already downloaded.

Этот пакет может прочитать и скачать любой. Для сохранения изменений в репозиторий нужен отдельный доступ: отправь Борису свой логин GitHub в вашем обычном личном канале. Не публикуй здесь фото/видео интерьера, подробные схемы электрики и систем безопасности, цены для клиента, закрытые ссылки, пароли или персональные данные — в том числе в issues, pull requests и вложениях. Для фактических данных объекта сначала согласуйте закрытое рабочее пространство. Папка `private/` исключена из Git только для защиты от случайной публикации; это **не** шифрование и не управление доступом. Перевод репозитория в закрытый режим не удалит ранее скачанные копии.

Pre-estimating aid only—not construction documents, a compliance determination, or permission to perform electrical work.

Только подготовка предварительной сметы — не рабочая документация, не заключение о соответствии нормам и не разрешение выполнять электромонтаж.
